# Python Expense Tracker

A command-line expense tracking application built with Python that helps users manage their monthly budget, track spending, and review saved expense history.

This project was developed to practice Python programming fundamentals while building a practical application.

## Features

- Enter monthly income and custom expense categories
- Calculate total expenses and remaining balance
- Identify highest, lowest, and average expenses
- Calculate spending percentages
- Display budget status and overspending warnings
- Validate user input to prevent common errors
- Save expense reports with timestamps
- View previously saved expense history
- Navigate through an interactive menu

## Technologies Used

- Python 3
- Visual Studio Code
- Git and GitHub

## Python Concepts Demonstrated

- Variables and data types
- Lists and loops
- Functions
- Conditional statements
- Input validation
- Exception handling
- File reading and writing
- Date and time formatting
- String formatting with f-strings

## How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

   python main.py

5. Follow the interactive menu to add expenses,
   view saved history, or exit.

Expense reports are saved locally to expenses.txt.
